# Threat Modeling Trigger Criteria

Run a full STRIDE threat model for any proposal introducing: a new external-facing endpoint, a new class of data exposure (e.g. first time exposing loyalty data externally), or a new trust boundary (e.g. new third-party integration with write access to an internal system).
