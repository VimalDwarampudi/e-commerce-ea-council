# Return Fraud Signal Sharing

**[MANDATORY]**

Return patterns indicating fraud (serial returners, wardrobing patterns) must be surfaced to Risk & Compliance and Payments' fraud detection systems, not siloed within the returns system. This is mandatory because return fraud is a material and growing loss category for retailers and cross-system signal sharing is the primary mitigation.
