# Returns Are a Fulfillment Flow, Not an Afterthought

Returns processing (receiving, inspection, restock-or-dispose decisioning, refund trigger) must be architected as a first-class reverse-fulfillment flow with the same rigor as forward fulfillment, not bolted on as a manual/exception process.
