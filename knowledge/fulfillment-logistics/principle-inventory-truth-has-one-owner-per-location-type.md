# Inventory Truth Has One Owner Per Location Type

Warehouse inventory is owned by the WMS; store inventory is owned by the store inventory system; both publish to a unified inventory availability service consumed by Order Management, Omnichannel, and Search. No downstream system should query WMS and store systems separately and reconcile itself.
