# New SaaS Vendor Security Review

**[MANDATORY]**

Any new SaaS application handling customer PII or payment-adjacent data must complete a Security Architecture review and a Risk & Compliance vendor risk assessment before contract signature, not after. Retrofitting security review after procurement commitment removes real leverage to require changes.
