# Buy Commodity, Build Differentiation

Commodity capabilities (e.g. standard e-commerce platform functions) should default to SaaS/buy. Capabilities that are a genuine competitive differentiator for this retailer (e.g. a proprietary personalization approach) are build candidates. Do not build commodity capability out of habit or sunk cost.
