# One Order, One Lifecycle, Many Fulfillments

An order can split across multiple fulfillments (ship-from-store, warehouse, backorder) but must remain one logical order with one customer-facing status view. Do not let fulfillment splitting leak into the customer experience as multiple disconnected order records.
