# Confidence Language Is a Trigger, Not a Conclusion

Phrases like 'we're confident this is safe' or 'this is a well-understood pattern' anywhere in a council deliberation should be treated as a prompt to look harder, not as a signal to stand down — that language is exactly where groupthink hides.
