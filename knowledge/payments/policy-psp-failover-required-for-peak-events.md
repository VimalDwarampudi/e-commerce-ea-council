# PSP Failover Required for Peak Events

**[MANDATORY]**

Payment processing must support automatic failover to a secondary PSP during peak load events (Black Friday, flash sales) or documented manual failover with a tested runbook. A single-PSP dependency with no failover path is a mandatory finding for any Major-impact peak-readiness review.
