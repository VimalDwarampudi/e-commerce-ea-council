# Peak Load Testing Before Major Sales Events

**[MANDATORY]**

Full-scale load testing against a validated peak traffic model is mandatory before Black Friday/Cyber Monday and any planned flash sale expected to exceed 5x normal traffic. Skipping this for a major event is a mandatory finding that blocks sign-off.
