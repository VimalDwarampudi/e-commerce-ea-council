# Store Associate Override Requires Audit Log

[RECOMMENDED]

Manual associate overrides (price override, inventory override for a sale despite system showing zero stock) must be logged with associate ID and reason code. Frequent override patterns are both a shrink-risk signal (Risk & Compliance) and an inventory-accuracy signal (Fulfillment & Logistics).
