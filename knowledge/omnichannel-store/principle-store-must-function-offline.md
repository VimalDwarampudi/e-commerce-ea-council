# Store Must Function Offline

POS and core store operations must degrade gracefully during connectivity loss — a store losing internet must still be able to sell, using locally cached pricing/inventory with reconciliation on reconnect. A store-wide outage from a WAN blip is an unacceptable single point of failure for physical revenue.
